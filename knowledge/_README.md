# Ask Bursa knowledge folders

Keep this file and the `.gitkeep` placeholders. Business owners can use **Knowledge Administration** in BursaIQ to upload a source, assign its owner and permitted roles, set version and lifecycle dates, and index it immediately. The page also supports re-indexing, removal, suggested-question review, and ingestion-failure inspection.

For command-line administration, add controlled documents only inside a department folder, then run `python scripts/ingest_knowledge.py`. Files beginning with `_` or `.` are not indexed.
