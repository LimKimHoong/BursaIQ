# Automation surface brief

Scope: a code-led Automation extension inside BursaIQ's incumbent world. Mode: Operate. Audience: the active demo identity planning recurring intelligence emails. Task: carry an Assistant question from Decision Canvas into an editable schedule, choose recipients, repetition, time zone and days, add briefing instructions and Link / Dashboard / Report content, then preview, save, edit or pause the plan.

The first-body contract in `index.html` governs the composition: page title and explicit demo boundary above a quiet schedule ledger on the left and an inline glass editor on the right, with New automation at upper right. Portrait and widths at or below 900px stack the ledger above the editor. Native fields retain 44px minimum targets; narrower phones stack inclusion choices and expand form actions. The signature moment is an answered question becoming a seeded, editable schedule. This precisely specified extension uses new-work §3's narrow-request exemption; no concept roll or FORM seed was generated.

Proof/content: each refreshed preview repeats a supported prepared question against available demo evidence, shows preparation and generation dates, checks the active identity's access, and exposes a source trail. Link returns to BursaIQ; Dashboard is an evidence snapshot; Report is an inline summary. Refreshing the preview does not save the schedule, and later edits clear the stale preview.

Constraints: preserve the incumbent violet/navy and pearl glass, system typography, line-led ledger, and existing semantic accents. Saved schedules are scoped by demo role in this browser, with no secure account-storage claim. Use demo email addresses. The user confirmed that no emails should be sent: the feature has no sender, background jobs, live feeds, arbitrary instruction execution, or real PDF attachments. Instructions are saved and displayed for a future connected model. Unsupported questions and unavailable evidence remain explicit; planned run times are demo calculations rather than live job commitments.

Unresolved decisions: none within this demo scope. Production scheduling, delivery and model integration are outside this extension.
